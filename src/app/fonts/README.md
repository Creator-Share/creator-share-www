# Reddit Sans

Unmodified upright variable font from [Google Fonts](https://github.com/google/fonts/tree/8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5/ofl/redditsans), commit `8b0a1d0f5983c89bc2b93f1b5fb55f9e252744b5`. Original filename: `RedditSans[wght].ttf`. Copyright Reddit, Inc.; distributed under the accompanying SIL Open Font License in `OFL.txt`.

SHA-256: `9a564474e5df96608ac1908c555a5f01f52a28d960b94d34c85a48153b0ac557`.

The application bundles this font through `next/font/local` so builds do not depend on Google's generated stylesheet URLs. Both the root layout and global not-found page share the same configuration, CSS variable, swap behavior, and 400 through 800 weight range.
